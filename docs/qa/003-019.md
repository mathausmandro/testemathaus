- Reprodução: 1) estar sem .env.local (ou sem NEXT_PUBLIC_SUPABASE_URL no ambiente); 2) `npm run build`; 3) `node node_modules/next/dist/bin/next start -p 3400`; 4) `GET http://localhost:3400/` e `GET /login`.

- Correção sugerida ao desenvolvedor: ligar validação em src/instrumentation.ts (register) com getPublicEnv e getServerEnv, ou o Mathaus aceitar o desvio e reescrever o critério. O dev alegou que a validação na inicialização quebraria o e2e e o Lighthouse sem .env.local; essa razão vale só para o build de teste, então a solução é condicionar pelo ambiente, não remover o critério.
